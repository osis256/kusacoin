# くさコイン

架空コインを売買して遊ぶ、共有相場のミニゲームです。プレイヤー名・残高・保有コインはブラウザーごとのプレイヤーとしてサーバーに保存され、3秒ごとの相場更新と売買が全プレイヤーに反映されます。総資産ランキングは現在価格で保有コインを評価します。

画面上の金額と価格は見た目の単位を100倍し、整数で表示します。成行・指値の注文数量も整数のみです。サーバー内部の残高は表示とは別の単位で管理します。

残高、保有コイン、各銘柄価格は毎日 00:00 JST に初期化されます。プレイヤー名は日付をまたいでも維持されます。銘柄ごとの値動きやすさは5段階からサーバー内で日ごとに抽選され、画面やAPIには公開されません。

売買手数料はありません。売買時には対称スプレッドと市場価格への影響を適用し、価格影響の合計は銘柄ごとに3秒あたり最大0.25%です。騰落率は直近10分を比較し、チャートは1分・10分・30分・1時間・6時間・1日から選べます。総資産が100葉未満の状態が60秒続くと、1日1回500葉の救済を受け取れます。

## 起動

Node.js 18 以降で実行します。

```sh
npm run build
npm start
```

ブラウザーで `http://localhost:3000` を開きます。ポートを変える場合は `PORT=8080 npm start` のように指定できます。

## コインを追加する

`coins.js` の配列に設定を追加します。`id` は一意の英数字、`initialPrice` は毎日の初期価格、`volatility` と `drift` は時間経過による小さな変動の基準値、`liquidity` と `maxImpact` は売買時の価格変動量、`characteristic` は画面に表示する値動きの説明です。画面の一覧・選択肢・保有欄・総資産計算には自動で追加されます。

プレイヤーと現在価格は `data/game-state.json` に保存されます。このファイルは Git の対象外です。コインと残高はゲーム内専用で、実在の通貨・金融市場には連動しません。
